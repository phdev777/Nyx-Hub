# Nyx Hub — site

Landing page da Nyx Hub, que faz software sob demanda. Feita com React, Vite, Tailwind v4 e motion.

- `npm install`, depois `npm run dev` (http://127.0.0.1:5173).
- `npm run build` gera a pasta `dist/`.
- **Textos e contatos:** `src/content.js`. Os itens marcados com "A CONFIRMAR" ainda dependem dos sócios.
- **Cores:** `src/index.css`, no bloco `@theme`. A paleta é a de `brand/paleta.png`: Prussian Blue #031130, Nyx Blue #185DF1 e Alice Blue #F3F7FE.
